# SVPT Pournami Pooja – test website

Test version of the Sri Varahi Prathyangira Temple Pournami Pooja status site and admin dashboard.

- Public: **Check status** by mobile number.
- Admin: dashboard (KPIs, charts, full data table), pooja progress, add data from Google Sheet link / Excel / CSV, manual entry.

**Test version:** there is no database yet. Everything the admin adds is saved only in that browser (localStorage). No devotee data is stored in this repository.

Built from the `pournami-portal` project (React + Vite) with `VITE_DEMO=1`.
